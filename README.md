# 💰 MyMoneyManager (용돈 및 지출 관리 웹 프로그램)

## 📌 프로그램 소개
일상 속 용돈과 지출 내역을 간편하게 기록하고, 현재 잔액 및 총 지출 현황을 한눈에 파악할 수 있도록 제작한 웹 기반 가계부 프로그램입니다. 별도의 프로그램 설치 없이 PC와 스마트폰 웹 브라우저에서 바로 사용할 수 있습니다.

## ✨ 주요 기능
- **수입 및 지출 내역 등록:** 날짜, 항목(내용), 금액을 입력하여 내역을 추가할 수 있습니다.
- **내역 조회 및 관리:** 기록된 지출 목록을 실시간으로 확인하고, 잘못 입력한 내역은 삭제할 수 있습니다.
- **금액 자동 계산:** 입력된 데이터를 바탕으로 총 수입, 총 지출, 현재 남은 잔액을 자동으로 계산해 보여줍니다.
- **반응형 웹 지원:** PC 화면뿐만 아니라 스마트폰 화면 크기에도 맞춰 편리하게 이용할 수 있습니다.

## 📖 사용 방법
1. 웹페이지 상단(또는 입력창)에서 **날짜, 내역(예: 점심 식사, 교통비 등), 금액**을 입력합니다.
2. **추가(등록) 버튼**을 클릭하면 아래 내역 리스트에 항목이 추가됩니다.
3. 상단 요약 영역에서 **총 지출 금액과 잔액**이 자동으로 업데이트된 것을 확인합니다.
4. 삭제가 필요한 항목은 해당 내역 옆의 **삭제 버튼**을 눌러 지울 수 있습니다.

## 🛠️ 사용 기술
- HTML5 / CSS3 / JavaScript
- GitHub Pages (웹 호스팅)
